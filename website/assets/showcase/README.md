# 官网能力截图

每个展示位采用 16:10 比例，建议截图宽度至少 1600px。现有 SVG 为占位图片，不是产品界面。

| 能力          | 占位文件            |
| ------------- | ------------------- |
| 远程连接      | remote-access.svg   |
| 多 Agent 协作 | multi-agent.svg     |
| 定时任务      | scheduled-tasks.svg |
| 文档能力      | documents.svg       |
| 内置浏览器    | browser.svg         |
| DOM 拾取      | dom-picker.svg      |

替换时，将 PNG / WebP 截图放在本目录，并更新 website/index.html 对应的 img src 和 alt。
展示位会保持比例，完整显示截图，不裁切界面。不同比例的截图会保留背景留白。
截图不要包含 API Key、登录令牌、个人账号或私人项目内容。
